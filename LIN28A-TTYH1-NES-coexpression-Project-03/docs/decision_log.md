# Decision log

One entry per analytical decision: what was chosen, what the alternatives were and why.

| # | Date | Decision | Alternatives considered | Rationale |
|---|---|---|---|---|
| 1 | 2026-11-05 | Repository scaffold: data/code/results separated, raw data git-ignored and re-downloadable from public accessions | Commit small processed matrices | Reviewers must be able to reproduce from public data with the repo alone; committed data would hide provenance and bloat history |
| 2 | 2026-11-05 | Stack: Python with anndata and PyDESeq2, pinned conda env | R + Seurat; hybrid Python ingest + R DE | The atlas is distributed as .h5ad; per-cell co-expression is direct on the sparse matrix; PyDESeq2 gives DESeq2 in the same environment, so one command runs everything |
| 3 | 2026-11-13 | Dataset scope: one multi-stage human fetal CNS atlas | Adding a whole-embryo atlas as a second check (planned on 2026-11-05, dropped) | The brief asks for the co-expressing cell states and their markers; one atlas with fine cell-type and stage labels answers both questions. A second atlas was outside the brief |
| 4 | 2026-11-05 | Primary dataset: Braun et al. 2023 first-trimester brain atlas (h5ad, 1.67M cells, 5 to 14 weeks) | Eze et al. 2021; whole-embryo atlases | Covers the earliest public brain window with many cells and donors; h5ad loads directly in backed mode; same cells as the authors' HumanFetalBrainPool.h5 |
| 5 | 2026-11-13 | Use the authors' quality-controlled cells and labels; no extra filtering | Own MAD-based filtering | The authors already removed low-quality cells and doublets; we only confirm raw counts and check depth per 10x kit |
| 6 | 2026-11-06 | Age bins early 5-7, mid 7.5-9.5, late 10-14 weeks | Single weeks; continuous age | Most weeks have 1-2 donors, so single weeks give no replicates |
| 7 | 2026-11-13 | 10x kit handled in the analysis, counts not corrected: detection per kit, cell-type test paired within donor, stage test with kit as covariate (~chemistry + group) | ComBat-seq on pseudobulk counts; downsampling v3 to v2 depth; stage test on v3 donors only | QC PCA: PC2 (25%) separates kits completely, PC1 (31%) follows age. Kit and age overlap, so changing the counts risks removing stage signal; a covariate keeps all donors (11 vs 5) |
| 8 | 2026-11-10 | Expressed = >= 1 UMI; co-expression = all three expressed; expected co-expression computed within depth quintiles per class x bin x kit x donor | Thresholds on normalised values; imputation | Raw-count definition is transparent; depth strata stop deep cells creating false co-expression; donors are the replicates |
| 9 | 2026-11-10 | Population defined at cluster level: authors' clusters with >= 500 v3 cells and triple-positive rate >= 5x the v3 background | Use triple-positive cells directly | LIN28A is in 0.33% of cells with <= 10 UMIs, so single-cell triple status is mostly sampling; a cluster-level state gives stable pseudobulk |
| 10 | 2026-11-10 | Markers by DESeq2 on donor x kit pseudobulk; axis 1 paired (~pair + group) vs all other early classes; axis 2 vs late radial glia; padj < 0.05 and log2FC >= 1 | Per-cell Wilcoxon | Cells from one donor are not independent; per-cell tests inflate significance |

| 12 | 2026-11-13 | Added a QC step (02_qc.py): missing values in counts and used metadata, kit batch PCA | Skip QC, rely on authors | Needed to decide on batch handling and to state that the data has no gaps |
| 13 | 2026-11-13 | Kit effect measured in the early bin (6 v2 vs 6 v3 donors, same age) and compared with mid and late | Assume the kit effect is the same at all ages | Correlation with the early kit effect is 0.72 (mid) and 0.53 (late). Removing it mixes v2 and v3 in early and mid; late v3 still separates from the single late v2 donor. Kit and late age cannot be fully separated, which is stated as a limitation |
