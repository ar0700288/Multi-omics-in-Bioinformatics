# Multi-omics in Bioinformatics

Projects that integrate more than one type of biological data. Each folder is a complete
project with its own code, results and documentation.

| Project | Summary |
|---|---|
| [CRC-Multiomics-Integration-Project-01](CRC-Multiomics-Integration-Project-01/) | Multi-omics integration pipeline for colorectal cancer survival prediction using MOFA2, Cox regression, Random Forest and XGBoost, with scRNA-seq validation (TCGA-COAD/READ). |
| [AD-glial-states-genetic-risk-Project-02](AD-glial-states-genetic-risk-Project-02/) | Tests whether the glial states Green et al. (2024) called causal in Alzheimer's disease carry inherited genetic risk, combining GWAS (MAGMA) with single-nucleus RNA-seq (scDRS). |
