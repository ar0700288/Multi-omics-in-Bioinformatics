# Multi-omics in Bioinformatics

Projects that integrate more than one type of biological data. Each folder links to its own
repository with the full code, results and documentation.

| Project | Summary |
|---|---|
| [CRC-Multiomics-Integration](https://github.com/ar0700288/CRC-Multiomics-Integration) | Multi-omics integration pipeline for colorectal cancer survival prediction using MOFA2, Cox regression, Random Forest and XGBoost, with scRNA-seq validation (TCGA-COAD/READ). |
| [AD-glial-states-genetic-risk](https://github.com/ar0700288/AD-glial-states-genetic-risk) | Tests whether the glial states Green et al. (2024) called causal in Alzheimer's disease carry inherited genetic risk, combining GWAS (MAGMA) with single-nucleus RNA-seq (scDRS). |

## Note

The project folders are links (git submodules) to the original repositories. To download a
collection together with all its projects:

```bash
git clone --recurse-submodules <this repository URL>
```
